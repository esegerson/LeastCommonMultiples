# LeastCommonMultiples
Small JavaScript algorithm to find the smallest number that has all factors between 2 and n, inclusive.

## Goal
Find the smallest number that has all factors between 2 and n, inclusive.

## Examples
For example, for n=4, find a number that can be divisible by 
4, 3, and 2. The smallest number that can be divisible by all of these numbers is 12, which is why some people argue for a base-12 numbering system.

Another example, for n=5, 60 is the smallest number that is divisible by 5, 4, 3, and 2. n=6 shares the same solution because 6 is a product of 2 and 3, which are already included.

420 is the smallest number that is divisible by 2, 3, 4, 5, 6, and 7.
